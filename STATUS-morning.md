# Статус проекта "Me" — актуально на 11 сент, день

Читай этот файл первым делом в новом чате. Дальше просто продолжай работу — ничего
переспрашивать не нужно, всё описано ниже.

## Правила (жёсткие, установлены пользователем, не менять без спроса)

1. Каждый рилс — сначала видео + карточка [Одобрить]/[Отклонить] в Telegram-бот
   пользователю (ADMIN_ID), публикация только после нажатия "Одобрить".
2. При "Отклонить" — бот спрашивает "что не так", ответ пользователя сохраняется
   как `reason` в таблице `queue`, дальше правишь и шлёшь заново.
3. Видео — только вертикальное 9:16 (1080×1920), не квадрат.
4. Обложки для IG-сетки — 1080×1350 (4:5), не полный кадр рилса, иначе обрежется
   в сетке профиля.
5. Деплой (`wrangler pages deploy`) РАЗРЕШЁН автономно, без подтверждения —
   гейт в `~/.claude/settings.json` (`autoMode.soft_deny`) снят пользователем лично
   11 сентября. `wrangler d1 execute` и `wrangler delete` остаются под гейтом.
6. Комментинг под чужими виральными постами (стратегия Aviasales) — банк готов в
   `content/brand/instagram/COMMENT-BANK.md`, пользователь одобрил тон. Лимит:
   3-5 комментариев в день на аккаунт (свежий IG, риск блокировки/чекпоинта).

## Секреты

- `ADMIN_KEY` — используется в заголовке `X-Admin-Key` для `/api/queue` и
  `/api/channel-post`. Значение НЕ хранится в git (секрет). Смотри
  `.secrets-local.md` в корне проекта (не в git, есть только локально) — если
  файла нет, спроси значение у пользователя (он его ставил в Cloudflare Pages
  → me-webapp → Settings → Variables and secrets).
- Секреты Pages применяются только после нового деплоя — если меняешь секрет,
  сразу передеплой (`wrangler pages deploy . --project-name me-webapp --commit-dirty=true`
  из `webapp/`), иначе будет "unauthorized" даже с верным ключом.

## API-шпаргалка (реально рабочие вызовы)

```bash
# Проверить что прод жив (403 = ок, 405 = сломан бандл функций)
curl -s -o /dev/null -w "%{http_code}\n" -X POST https://me-webapp.pages.dev/webhook

# Пост в канал t.me/me_zdorovie (video ИЛИ text, поля media/text — НЕ video_url/caption)
curl -X POST https://me-webapp.pages.dev/api/channel-post \
  -H "X-Admin-Key: $(cat /Users/robert/Desktop/Projects/ME/.secrets-local.md)" -H "Content-Type: application/json" \
  -d '{"media":"https://me-webapp.pages.dev/media/ИМЯ.mp4","text":"подпись"}'

# Отправить рилс на одобрение в бот (video_url ВНУТРИ payload, .mp4 обязателен)
curl -X POST https://me-webapp.pages.dev/api/queue \
  -H "X-Admin-Key: $(cat /Users/robert/Desktop/Projects/ME/.secrets-local.md)" -H "Content-Type: application/json" \
  -d '{"kind":"reel","title":"Название","body":"на одобрение","payload":{"video_url":"https://me-webapp.pages.dev/media/ИМЯ.mp4"}}'
```
