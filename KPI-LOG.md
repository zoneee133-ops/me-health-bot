# KPI-LOG

Еженедельная проверка порогов перехода между стадиями `ROADMAP.md`
(IG-подписчики, активные юзеры бота) — запускается после Weekly Reel
Analysis, перед Weekly Director Report.

---

## 2026-09-14 — ДАННЫХ НЕТ, ПОРОГ НЕ ПРОВЕРЕН

**Текущая стадия по ROADMAP.md:** Стадия 1 («Автоматизация без ручных
пинков») — по `WEEKLY-REPORT.md` за 2026-09-14 ещё не завершена
(автопроверка рилсов готова, публикация по графику/контроль follow-листа/
еженедельный анализ — ещё переводятся на cron). Числовые пороги перехода
Стадия 1 → 2 нечисловые (полный цикл автоматизации без ручного
вмешательства), а точный числовой порог конца Стадии 2 (1000 IG-подписчиков?
15 юзеров бота? оба?) сам ROADMAP.md пока оставляет открытым вопросом
(раздел «Открытые вопросы»).

**Файл с цифрами не найден.** Искал `content/brand/instagram/METRICS.md`
и любые другие md-файлы с цифрами подписчиков/юзеров бота
(`grep -rli` по подпискам/юзерам/followers) — в репозитории такого файла
нет вообще. `COMPETITOR-RESEARCH.md` есть, но это цифры по конкурентам,
не по нашему аккаунту/боту. `WEEKLY-REPORT.md` за эту же неделю тоже прямо

**Действие:** по инструкции задачи — нет свежих данных, значит порог
сравнить не с чем. `ROADMAP.md` не менялся. Ничего не выдумано.

**Нужно от владельца:** завести файл (например
`content/brand/instagram/METRICS.md`) с актуальными цифрами IG-подписчиков
и активных юзеров бота и обновлять его не реже раза в 10 дней — иначе эта
еженедельная проверка порогов не сможет ничего сравнивать ни на одном
следующем запуске.
