# Плавающий таб-бар «Float» — MVP дизайна

> Только дизайн-спека. Код основного интерфейса (`Me_MVP_v6.html`) не трогаем.
> Референс: pin.it/2fCuOWcBo — «Menu Bar UI/UX Design». Плавающая белая пилюля-навбар,
> оторванная от края экрана, с отдельной круглой акцентной кнопкой, которая
> выступает из левого верхнего угла бара.

---

## 1. Что меняется

Сейчас в проекте: `.tabbar` — панель во всю ширину, прижата к низу, `backdrop-blur`,
верхняя граница-хайрлайн, активный таб помечен коротким штрихом сверху (`.tab.active::before`).

Становится: **плавающая пилюля**, не касается краёв, лежит на «подушке» из тени.
Активный таб подсвечивается **жидким индикатором-каплей**, который переезжает между
иконками с пружиной. Плюс **вынесенная акцентная кнопка** (контекстное действие) слева.

Экраны, переходы между табами, вся логика — без изменений. Это чисто оболочка навигации.

---

## 2. Анатомия

```
        ┌────┐
        │ ☰  │  ← accent action (Ø 44), перекрывает бар сверху-слева на ~40%
   ┌────┴────┴──────────────────────────────────┐
   │   ●        ○        ○        ○        ○     │  ← float bar (пилюля)
   │  home    health    meds     ask    profile │
   └────────────────────────────────────────────┘
   └ 16px ┘                              └ 16px ┘   отступ от краёв device
                       └ 24px ┘                     отступ от низа (над home-indicator)
```

| Элемент | Размер | Токен |
|---|---|---|
| Бар: высота | 60px | — |
| Бар: радиус | 30px (полная пилюля) | — |
| Бар: фон | `rgba(255,255,255,0.82)` + `backdrop-filter: blur(24px) saturate(1.4)` | на базе `--surface` |
| Бар: тень | `0 8px 32px -8px rgba(20,20,18,0.16), 0 2px 8px rgba(20,20,18,0.06)` | ср. `--shadow-card` |
| Бар: обводка | `1px solid rgba(255,255,255,0.6)` внутренняя (glass edge) | — |
| Отступы | `left/right: 16px`, `bottom: calc(env(safe-area-inset-bottom,0) + 12px)` | — |
| Иконка таба | 24px, `stroke-width` как сейчас | `--ink-3` / активная `--accent` |
| Индикатор-капля | Ø 44, `background: var(--accent-soft)` | — |
| Accent action | Ø 44, `linear-gradient(180deg, var(--accent), var(--accent-dark))` | как `.voice-btn` |
| Accent action: тень | `0 6px 16px -4px rgba(15,76,92,0.45)` | — |
| Accent action: позиция | `left: 8px; top: -16px` (выступает над баром) | — |

Иконки и порядок табов — те же 5, что в `Me_MVP_v6.html` (`today / health / meds / ask / profile`).
Подписи под иконками **убираем** — только у активного таба (см. п.3, вариант B).

## 3. Эффекты

### 3.1 Переезд индикатора (главный эффект)

При тапе по табу капля `--accent-soft` переезжает под новую иконку.

- **Трансформ:** `transform: translateX(...)` по позиции таба, не `left` (GPU).
- **Кривая:** `cubic-bezier(0.32, 0.72, 0, 1)` — та же пружина, что везде в проекте.
- **Длительность:** 420ms.
- **Squash:** во время переезда капля растягивается по X (`scaleX(1.35)`), в конце
  возвращается к `scaleX(1)` — эффект «жидкости». Реализация: keyframes или
  два перехода (width на разгоне → назад).

### 3.2 Иконка

- Активная: `color: var(--accent)`, `transform: scale(1.06) translateY(-1px)`.
- Неактивная: `color: var(--ink-3)`, `scale(1)`.
- Переход `240ms ease`, с задержкой `60ms` относительно старта капли — иконка
  «догоняет» индикатор.

### 3.3 Подпись активного таба (вариант B, рекомендую)

Бар в покое показывает только иконки. У активного — подпись выезжает справа от
иконки, бар локально расширяет эту ячейку (как Material 3 pill nav).

- Подпись: `font-size: 11px; font-weight: 600; color: var(--accent)`.
- Появление: `opacity 0→1` + `max-width 0→48px`, `200ms`, задержка `120ms`
  (после того как капля приехала).
- При уходе с таба — мгновенно (`opacity 0`, `80ms`), без задержки.

Если сложно — **вариант A:** подписей нет вообще, только иконки + капля. Тоже валидно для MVP.

### 3.4 Тап (нажатие)

- Вся ячейка таба: `active:scale(0.92)`, `120ms`. Уже есть паттерн в `.tab:active`.
- Haptic: `navigator.vibrate?.(8)` на смене таба (если доступно).

### 3.5 Accent action

Контекстная кнопка. Меняет иконку/действие в зависимости от активного экрана:

| Экран | Иконка | Действие |
|---|---|---|
| today | `+` | Загрузить анализ |
| health | `+` | Добавить документ |
| meds | pill | Добавить приём |
| ask | mic | Голосовой ввод |
| profile | — | скрыта |

- Смена иконки при переключении экрана: `crossfade` 180ms + `rotate(-90deg→0)`.
- Скрытие (profile): `scale(0.6)` + `opacity 0`, `220ms` пружина; бар при этом не двигается.
- Тап: `active:scale(0.9)`, затем открытие соответствующего sheet/upload.

### 3.6 Появление бара при старте

- Бар: `translateY(120%) → 0`, `520ms`, пружина, задержка `200ms` после загрузки экрана.
- Accent action: та же анимация, задержка `+80ms` (выезжает следом).
- Капля под первым табом: `scale(0) → 1`, `300ms`, задержка `+260ms`.

### 3.7 Скролл-поведение (опционально, за MVP)

Прячем бар при скролле вниз, показываем при скролле вверх — `translateY` +
`opacity`. Помечено как post-MVP: сначала базовый статичный плавающий бар.

---

## 4. `prefers-reduced-motion`

- Капля переезжает без squash, `120ms ease` вместо пружины.
- Появление бара: просто `opacity`, без `translateY`.
- Смена иконки accent action: мгновенная.

---

## 5. Что НЕ входит в MVP

- Скролл-скрытие бара (п.3.7).
- Кастомный blur-fallback для браузеров без `backdrop-filter` (сейчас в проекте
  уже так — оставляем `rgba` фон плотнее как fallback).
- Реордер / кастомизация табов.
- Бейджи-счётчики на иконках.
