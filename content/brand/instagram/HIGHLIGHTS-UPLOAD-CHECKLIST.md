# Чек-лист: загрузка Instagram Highlights для @me_abouthealth_bot

Исполнитель: любой человек вручную, или бот-автоматизация позже. Аккаунт сейчас не трогаем — этот файл только инструкция.

Источник данных: `content/brand/instagram/HIGHLIGHTS.md` (7 хайлайтов, у каждого обложка + 2-3 стори-кадра, все файлы `content/brand/instagram/hl-*.png`).

---

## Как обойти проблему с web-загрузкой stories

**Проблема:** на instagram.com (desktop) в сайдбаре кнопка «Создать» открывает только форму для ленты (пост/рилс/карусель) — опции «Story» там нет. Кнопка «＋» рядом с аватаркой профиля (где обычно добавляют в Highlights) активна только когда у аккаунта уже есть хотя бы одна опубликованная story за последние 24ч — а у этого аккаунта их 0, замкнутый круг.

**Рабочий метод (подтверждён по актуальным источникам, 2025-2026): эмуляция мобильного user-agent через DevTools браузера.** Instagram отдаёт мобильную web-версию (m.instagram.com layout) с полноценной кнопкой загрузки Story, если браузер представляется телефоном. Официально не поддерживается Meta, но стабильно работает у пользователей:

1. Открыть instagram.com в Chrome, залогиниться под аккаунтом бота.
2. Открыть DevTools: `F12` (Windows) или `Cmd+Opt+I` (Mac), либо правый клик → «Просмотреть код» / Inspect.
3. В DevTools нажать иконку «Toggle device toolbar» (значок телефон+планшет, обычно вверху слева панели DevTools) — включает эмуляцию мобильного устройства. Выбрать любой профиль телефона (iPhone 14 Pro и т.п.).
4. Обновить страницу (F5) с включённой эмуляцией — интерфейс должен перестроиться в мобильный.
5. В верхнем левом углу ленты появится значок камеры (тот же, что в приложении для создания Story) — он не зависит от того, есть ли уже опубликованные stories. Именно через него загружаем файлы.
6. Кликнуть на значок камеры → выбрать «Загрузить из галереи/компьютера» → указать нужный PNG-файл.
7. Ограничения этого метода: стикеры (музыка, опрос, вопрос, таймер, "Add Yours"), рисование и часть фильтров могут быть недоступны или работать нестабильно — это не критично, т.к. наши кадры — уже готовые статичные PNG без интерактивных стикеров. Публикация мгновенная, отложенного постинга через этот метод нет.

**Резервный метод, если DevTools-трюк перестанет работать:** Meta Business Suite (business.facebook.com/latest/posts или business.instagram.com) — для Business/Creator-аккаунта поддерживает загрузку Stories с desktop без танцев с user-agent, включая отложенную публикацию. Требует привязки аккаунта к Meta Business Suite (Facebook Business Manager) — сделать один раз заранее.

**Самый надёжный вариант, если оба выше подведут:** мобильное приложение Instagram — на телефоне или в эмуляторе Android (например, Android Studio emulator / Genymotion на Mac с установленным Instagram apk). Залогиниться, «+» → Story → выбрать фото из галереи (файлы предварительно перекинуть на телефон через AirDrop/облако/USB). Это единственный способ гарантированно получить весь набор функций (стикеры, текст, geotag), но нам они не нужны для этой загрузки.

## Пошаговый процесс на каждый хайлайт

1. Загрузить все N stories этого хайлайта по порядку (метод — см. раздел выше про обход desktop-ограничения). Между кадрами не публиковать чужие/сторонние stories, чтобы порядок в Highlight собирался предсказуемо.
2. На странице профиля (desktop-режим, без эмуляции — обычный интерфейс) под аватаркой должна появиться кнопка «＋ Новое» рядом с Highlights (она включается сама, как только на аккаунте появилась ≥1 активная story — после шага 1 это условие выполнено).
3. Нажать «＋ Новое» → выбрать только что опубликованные N stories этого хайлайта, в правильном порядке 1→N.
4. Нажать «Далее» → «Изменить обложку» → загрузить `hl-<slug>-cover.png` (контент по центру кадра — Instagram обрезает обложку в круг, у файла уже безопасный кроп).
5. Ввести название хайлайта (см. таблицу выше) → «Готово»/«Добавить».
6. Проверить порядок хайлайтов на странице профиля, при необходимости перетащить (drag) в порядок 7→1→2→3→4→5→6.
7. Повторить для следующего хайлайта.

## После всех 7

- Проверить, что каждый Highlight открывается, кадры идут в заявленном порядке, обложки не обрезаны криво.
- Исходные PNG остаются в `content/brand/instagram/` как архив на случай пересборки.
