# Тексты для @BotFather

Большинство ставится автоматически через `/setup` (см. SETUP.md).
Здесь — то, что BotFather принимает только вручную в чате, + запасные копии.

---

## /setname
```
Me — здоровье понятным языком
```

## /setdescription  (текст на экране бота до первого запуска)
```
Me переводит медицинские данные на понятный язык. Сфотографируйте анализ или рецепт — приложение распознаёт показатели и объясняет каждый простыми словами, строит календарь приёма лекарств, фиксирует визиты к врачу и собирает отчёт, который можно принести на приём. Есть чат по вашим данным и доступ для близких.
```

## /setabouttext  (короткое, в профиле бота, до 120 симв.)
```
Понимает ваши анализы и рецепты — объясняет простыми словами. Анализы, лекарства, визиты, отчёт врачу.
```

## /setcommands
```
start - Открыть приложение Me
help - Как это работает
```

## /setuserpic
Залей логотип 512×512 (сердце/капля в фирменном indigo #212842 на кремовом #F0E7D5).

## Menu button
`/setmenubutton` → выбрать бота → *Configure menu button* →
- URL: `https://me-webapp.pages.dev`  (твой адрес Pages)
- Текст: `Открыть Me`

*(если делал `/setup` — кнопка уже стоит, менять не нужно)*

## Регистрация Mini App (для красивой ссылки t.me/твойбот/app и превью)

`/newapp` → выбрать бота →
- Title: `Me`
- Short description: `Здоровье понятным языком`
- Photo 640×360, GIF-демо по желанию
- Web App URL: `https://me-webapp.pages.dev`
- Short name: `app`  → ссылка станет `t.me/твойбот/app`
