# Me

ИИ-помощник, который переводит медицинские данные пациента на понятный язык.

Пользователь фотографирует анализ или рецепт → ИИ распознаёт и объясняет каждый показатель
простыми словами → строит календарь приёма лекарств → фиксирует визиты к врачу →
по запросу собирает отчёт для следующего приёма. Плюс чат по своим данным и доступ для близких.

## Структура

| путь | что |
|---|---|
| `webapp/index.html` | Telegram Mini App (фронтенд, весь UI) |
| `worker/` | Cloudflare Worker: ИИ-прокси на Gemini, БД D1, вебхук бота, пуши |
| `Me_MVP_v6.html` | исходный дизайн-прототип (референс, не деплоится) |
| `design/` | демо отдельных элементов |
| `SETUP.md` | пошаговый запуск в Telegram |
| `BOTFATHER.md` | тексты и настройки бота |

## Запуск

См. **[SETUP.md](SETUP.md)**. Стек полностью бесплатный (Cloudflare free tier + Gemini free tier).

## Дисклеймер

Me не ставит диагнозы и не заменяет консультацию врача. Все объяснения — справочные.
