# Roadmap — до первого платящего подписчика

Дата создания: 2026-09-11. Финальная точка: первый реальный незнакомый
человек оплатил подписку через Telegram Stars. Старт: см. «Стадия 0».

Автоматизация построена на **cron/scheduled routines**, не на иерархии
агентов, которые пинают друг друга. Причина: LLM-агент без триггера просто
стоит — «менеджер» и «воркер» не работают 24/7 сами, их должен разбудить
таймер. Оргструктура директор→менеджер→воркеры не даёт возможностей, только
задержку и расход токенов на пересказ контекста.

---

## Стадия 0 — Текущее состояние (зафиксировано 2026-09-11)

- IG-подписчиков: < 50
- Активных юзеров бота: < 15
- Рилсы A-H: часть live (A, B), часть в очереди на одобрение (E-H), C/D ждут
  причину отказа
- Follow-лист чистится (был перекос на блогеров 3-5к+, исправляется на
  обычных юзеров, лимит 200)
- Комментная стратегия v2 (нишевая: caregiver/health, не mass-grind) — файл
  `content/brand/instagram/COMMENT-BANK.md`
- Платежей нет вообще, инфраструктуры нет

## Стадия 1 — Автоматизация без ручных пинков (следующий шаг)

Разделение по типу нагрузки:

- **Тяжёлый рендер (Remotion+TTS)** — остаётся на локальной машине (бесплатно),
  но не по требованию каждый раз: раз в неделю, когда комп открыт для
  еженедельной проверки, накопить буфер готовых рилсов на несколько дней/недель
  вперёд.
- **Лёгкие операции — в облаке по cron, не зависят от того, включён ли комп:**
  - публикация из буфера по графику (IG + Telegram-канал)
  - комменты по `COMMENT-BANK.md` v2 в нишевых аккаунтах (лимит: не спамить,
    редкий разнесённый темп)
  - контроль follow-листа (не превышать 200, чистка блогеров)
  - еженедельный анализ: какой рилс/сегмент лучше залетает → предложение
    нового формата в `CONTENT-PLAN-DRAFT-NEW-IDEAS.md`
  - еженедельный отчёт-сводка одним файлом — это и есть тот самый «раз в
    неделю зайти и посмотреть»

Условие перехода на Стадию 2: cron-рутины настроены и минимум 1 полный цикл
прошёл без ручного участия.

## Стадия 2 — Рост аудитории до порога

Приоритет пользователя: сначала рост, платёж — потом, но не блокировать
подготовку.

- Цель по бот-юзерам: 15 (уже была целью)
- Рост IG через follow/комменты v2, ссылка в шапке профиля на бота
- Пока это идёт — Telegram Stars можно тихо готовить параллельно (см. Стадия 3),
  чтобы не терять время, интеграция не мешает росту

Условие перехода на Стадию 3: рост стабилен (бот получает новых юзеров без
провалов несколько недель подряд) — точный числовой порог (1000 подписчиков
или 15 юзеров) фиксируем как триггер для реального запуска платежа, не для
начала кода.

## Стадия 3 — Платёжная инфраструктура

- Механизм: **лимит запросов** — N бесплатных расшифровок/расписаний в месяц,
  дальше платно
- Приём платежа: **Telegram Stars** — не нужна отдельная регистрация ИП/офоферта
  на старте, всё внутри Telegram
- Кодит это агент (не ты — ты не программист), тебе на проверку — что именно
  проверяешь, обсудим отдельно перед запуском
- Лимит N подобрать по факту использования (сколько запросов делает активный
  юзер сейчас в среднем) — нужна эта цифра перед тем как ставить N

## Стадия 4 — Тест механизма

- Прогнать оплату на тесте (сам/друг) — только техническая проверка, что Stars
  проходят и лимит снимается правильно, это НЕ считается финальной точкой

## Стадия 5 — Финал: первый платящий незнакомец

- Реальный чужой человек уперся в лимит и оплатил Stars — roadmap выполнен
